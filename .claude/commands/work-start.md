# /work-start — 오늘 업무 시작

## 핵심 정보
- 업무 일지 DB data-source: `.claude/notion-pages.md` 참조
- 현재 스프린트 URL: `.claude/notion-pages.md` 업무 일지 항목 참조
- 일별 항목 제목 형식: `YYYY-MM-DD (요일)` (요일: 월화수목금토일)

## 실행 흐름

1. 오늘 날짜 및 요일 확인
2. **월요일이면** → 새 스프린트 항목 생성 먼저 제안
   - 제목: `[OKR 26년 2분기] 스프린트 N주차`
   - 날짜: 이번 주 월~금 (date range)
   - OKR 연결: 해당 주 목표 입력받기
   - 생성 후 notion-pages.md 업데이트
3. `notion-pages.md`에서 현재 스프린트 URL 확인
4. 현재 스프린트 페이지 `notion-fetch`로 불러와 이번 주 할 일 목록 확인
5. 오늘 날짜로 이미 일별 항목 있는지 확인 (있으면 링크 안내 후 종료)
6. 스프린트 기반으로 오늘 할 일 추출:
   - 오늘 마감(`~오늘 날짜`) 항목 우선
   - 미완료 이월 항목
   - 적정 수: 3~5개
   ```
   오늘 할 일 제안 (스프린트 3주차 기반):
   - [ ] 항목 — 이유/마감
   - [ ] 항목 — 이유/마감

   추가하거나 뺄 것 있나요?
   ```
7. 사용자 확인 후 업무 일지 DB에 일별 항목 생성 (`notion-create-pages`)
8. 생성 완료 후 페이지 URL 안내

## 생성되는 일별 항목 구조

```
제목: YYYY-MM-DD (요일)
날짜: 오늘
OKR 연결: 스프린트 N주차 참조
상태: 진행중
아이콘: 📅
```

## 규칙
- 스프린트 항목이 없으면 → "이번 주 스프린트가 없습니다. 생성할까요?" 질문
- 태스크는 3~5개 (너무 많으면 부담)
- 생성 후 반드시 notion-pages.md 업무 일지 항목 목록 업데이트
