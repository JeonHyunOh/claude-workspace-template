# /meeting — 회의록 노션 저장

## 목적
회의 내용을 날짜+주제로 노션 회의록 페이지에 자동 저장한다.

## 실행 흐름

### 1단계 — 회의 정보 수집

스킬 호출 시 내용이 함께 제공된 경우 바로 2단계로 진행.
내용이 없으면 아래 질문:

```
회의 주제가 무엇인가요?
회의 내용을 간단히 말씀해 주세요. (참석자, 논의 내용, 결정사항, 액션아이템 등)
```

### 2단계 — 노션 페이지 생성

`notion-pages.md`에서 회의록 페이지 ID 확인 후 하위에 새 페이지 생성.

- 제목 형식: `YYYY-MM-DD {회의 주제}`
- 생성 툴: `notion-create-pages`
- 상위 페이지: `notion-pages.md`의 📝 회의록 페이지 ID

생성되는 페이지 구조:
```
## 📋 회의 개요
- 일시: YYYY-MM-DD
- 참석자: (입력값 또는 생략)

---

## 💬 논의 내용
(사용자 입력 내용)

---

## ✅ 결정사항
(입력값 또는 "-")

---

## 📌 액션아이템
(입력값 또는 "-")
```

### 3단계 — notion-pages.md 업데이트

회의록 항목(최근) 표에 추가:
```
| {제목} | {URL} | {날짜} |
```

### 4단계 — 완료 안내
```
회의록이 저장됐습니다.
{노션 페이지 URL}
```

## 규칙
- notion-pages.md에 회의록 페이지 ID가 없으면 → "/setup을 먼저 실행해주세요." 안내 후 중단
- 참석자, 결정사항, 액션아이템은 사용자가 언급하지 않으면 "-" 처리
- 제목에 특수문자 포함 시 노션 호환 형태로 변환
