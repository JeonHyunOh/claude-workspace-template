# /memo — 업무 메모 저장

## 목적
업무 중 궁금한 것, Claude에게 물어본 것, 아이디어, 참고 사항을 노션에 빠르게 저장한다.

## 실행 흐름

1. 메모 내용 확인
   - `/memo 내용` 형태로 바로 입력했으면 그대로 사용
   - `/memo`만 입력했으면 → "어떤 내용을 메모할까요?" 질문
2. 메모 유형 자동 분류 (묻지 않고 내용 기반으로 판단):
   - ❓ **Q&A** — Claude에게 물어본 질문 + 답변 요약
   - 💡 **아이디어** — 떠오른 생각, 개선 아이디어
   - 📌 **참고** — 나중에 볼 링크, 정보, 용어 정리
   - 📝 **메모** — 그 외 일반 메모
3. `.claude/notion-pages.md`에서 업무 메모 페이지 URL 확인
4. `notion-create-pages`로 메모 항목 생성:

```
제목: [유형 이모지] 제목 (핵심 키워드 기반 자동 생성)
날짜: 오늘
태그: 유형

--- 내용 ---
## 질문 / 내용
{사용자가 입력한 내용}

## 답변 / 정리
{Claude의 답변 또는 관련 정보 요약}

## 참고
{관련 링크, 출처 등 (있을 경우)}
```

5. 생성 완료 후 페이지 URL 안내

## 빠른 저장 패턴

대화 중에도 언제든 호출 가능:
- "이거 메모해줘" → 현재 대화 내용 기반으로 자동 저장
- "방금 답변 노션에 저장해줘" → 직전 Claude 답변을 Q&A 형태로 저장
- `/memo {내용}` → 바로 저장

## 규칙
- 제목은 15자 이내로 핵심만 (검색 용이성)
- 답변 요약은 3~5줄 이내로 간결하게
- 저장 후 notion-pages.md 업무 메모 섹션 업데이트
- 노션 메모 페이지가 없으면 → 메인 페이지 하위에 "💼 업무 메모" 페이지 생성 후 진행
