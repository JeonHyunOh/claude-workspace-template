# /setup — 워크스페이스 최초 설정

## 목적
처음 이 템플릿을 클론한 사람이 자신의 워크스페이스로 만드는 온보딩 스킬.
완료 후 `/work-start` 로 바로 업무를 시작할 수 있는 상태가 된다.

## 실행 흐름

### 1단계 — 기본 정보 수집
아래 항목을 순서대로 질문한다. 한 번에 하나씩.

```
안녕하세요! 워크스페이스 설정을 시작할게요. 몇 가지 여쭤볼게요.

1. 이름이 어떻게 되세요?
2. 소속(회사/팀)과 역할은요?
3. 합류일은 언제인가요? (예: 2026-04-01)
```

### 2단계 — 노션 연결 확인
```
노션 MCP가 연결되어 있나요?
Claude Desktop → 설정 → 통합(Integrations) 에서 Notion이 연결되어 있어야 합니다.

연결됐다면 워크스페이스로 사용할 노션 페이지 URL을 붙여넣어 주세요.
(빈 페이지여도 됩니다. 구조를 잡아드릴게요.)
```

- `notion-fetch`로 페이지 접근 확인
- 접근 실패 시 → "Notion MCP 연결을 먼저 확인해주세요." 안내 후 중단

### 2.5단계 — 노션 페이지 구조 자동 생성

메인 페이지 하위에 아래 구조를 자동으로 만든다:

```
{메인 페이지}
├── 📋 업무 일지 (DB)   ← notion-create-database
├── 📝 회의록           ← notion-create-pages
└── 💼 업무 메모        ← notion-create-pages
```

- `notion-create-database` — 업무 일지 DB 생성 (제목, 날짜, 상태, OKR 속성 포함)
- `notion-create-pages` — 회의록 페이지 생성 (빈 페이지, 회의록 보관용)
- `notion-create-pages` — 업무 메모 페이지 생성 (빈 페이지, 메모 보관용)
- 생성 완료 후 각 페이지 URL/ID를 `.claude/notion-pages.md`에 기록

이미 페이지가 있는 경우:
```
이미 사용 중인 노션 페이지가 있으신가요?
각 항목의 URL을 붙여넣어 주시면 연결해드릴게요.
(없는 항목만 새로 만들겠습니다.)
```

### 3단계 — 파일 자동 생성

수집한 정보로 아래 파일들을 업데이트한다.

**`.claude/user-config.md` 업데이트:**
```
이름: {입력값}
소속: {입력값}
역할: {입력값}
합류일: {입력값}

노션_메인_URL: {입력값}
노션_업무일지_DB_URL: {입력값}
```

**`.claude/notion-pages.md` 업데이트:**
- 메인 페이지 URL/ID 채우기
- 업무 일지 DB URL/ID + data-source ID 채우기

**`CLAUDE.md` 하단 업데이트:**
```
## [업데이트] 현재 업무 상황
- {소속} {역할} 온보딩 중
- 합류일: {합류일}

**마지막 업데이트: {오늘 날짜}**
```

### 4단계 — 문서 폴더 구성

```
현재 어떤 프로젝트나 업무를 담당하고 계세요?
docs/ 폴더를 업무에 맞게 구성해드릴게요.
(예: gwd, vibecoding, 영업, 기획 등 / 모르면 나중에 해도 됩니다)
```

- 입력받은 프로젝트명으로 `docs/{프로젝트}/meetings/`, `docs/{프로젝트}/plans/` 폴더 생성
- 건너뛰면 → `docs/` 폴더만 유지, 나중에 직접 추가
- CLAUDE.md 문서 구조 섹션 업데이트

### 5단계 — git 커밋 안내
```
설정이 완료됐습니다! 🎉

이제 변경사항을 내 레포에 저장할게요.
아래 명령어를 터미널에 입력하세요:

  git add .
  git commit -m "setup: 워크스페이스 초기 설정"
  git push

완료 후 /work-start 로 오늘 업무를 시작해보세요.
```

## 규칙
- 노션 MCP 연결 안 된 경우 → 2단계에서 중단, 연결 방법 안내
- 이미 user-config.md가 채워진 경우 → "이미 설정된 워크스페이스입니다. 재설정할까요?" 확인 후 진행
- 설정 완료 후 notion-pages.md 반드시 업데이트
- 문서 폴더 구성은 선택 사항 — 건너뛰어도 나중에 언제든 추가 가능
