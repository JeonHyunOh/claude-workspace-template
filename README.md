# Claude 업무 워크스페이스 템플릿

> Claude Code + Notion으로 매일 업무를 자동 정리하는 비서 워크스페이스 템플릿

---

## 이 템플릿은 "틀"입니다

이 레포는 완성된 도구가 아니라 **출발점**입니다.

기본 구조(스킬, 노션 연동, 파일 레이아웃)는 잡혀 있지만, 실제로 쓸만한 비서가 되려면 **내 업무 방식에 맞게 고쳐야** 합니다.

### 무엇을 커스텀할 수 있나요?

| 항목 | 예시 |
|------|------|
| **CLAUDE.md 역할 정의** | "나는 마케터야, 캠페인 일정 중심으로 정리해줘" |
| **스킬 추가/수정** | `/meeting` 회의록 스킬, `/weekly` 주간 리뷰 스킬 등 |
| **노션 구조** | 내 노션 DB 이름, 페이지 ID에 맞게 재연결 |
| **docs/ 폴더 구성** | 내 프로젝트 이름으로 폴더 추가 |
| **할 일 제안 방식** | 스프린트 기반 → OKR 기반, 칸반 기반 등으로 변경 |

### 커스텀 흐름

```
1. /setup 으로 기본 개인 설정 완료
2. CLAUDE.md 하단 "현재 업무 상황" 채우기
3. 쓰다 불편한 부분 → Claude에게 "이렇게 바꿔줘"
4. 필요한 스킬 추가 → .claude/commands/ 에 파일 추가
```

> "CLAUDE.md 업데이트해줘", "이 스킬 수정해줘" 라고 말하면 Claude가 직접 파일을 고쳐줍니다.

## 이 템플릿으로 할 수 있는 것

### 📋 매일 업무 일지 자동 생성
`/work-start` 한 번으로 오늘 할 일을 노션에 만들어줍니다.
스프린트 기반으로 오늘 마감 항목, 이월 항목을 분석해 3~5개를 제안하고, 확인하면 노션 페이지가 자동 생성됩니다.

### ✅ 하루 마무리 자동 기록
`/work-end`로 오늘 완료한 것/못한 것을 정리하면, 노션 일지를 업데이트하고 내일 할 일까지 미리 만들어줍니다.

### 📅 스프린트 관리
매주 월요일에 `/work-start`를 실행하면 새 스프린트 생성을 제안합니다. OKR 연결, 날짜 범위 자동 설정.

### 💬 질문·메모 즉석 저장
Claude에게 물어본 것, 아이디어, 참고 정보를 "이거 메모해줘" 한 마디로 노션에 기록합니다.
대화 중 나온 답변도 Q&A 형태로 바로 저장 가능합니다.

### 🗂️ 로컬 문서 정리
`docs/` 폴더를 프로젝트별로 구성해 회의 자료, 기획 문서를 체계적으로 보관합니다.

## 시작하기

### 1. 이 템플릿으로 내 레포 만들기
GitHub에서 **Use this template** → 내 계정에 레포 생성

### 2. 로컬에 클론
```bash
git clone https://github.com/{내계정}/{레포이름}
cd {레포이름}
```

### 3. Notion MCP 연결
Claude Desktop → 설정 → 통합(Integrations) → Notion 연결

### 4. Claude Code 실행 후 /setup
```
/setup
```
이름, 소속, 노션 URL 등을 물어보며 개인 설정을 자동으로 완료합니다.
노션 업무 일지 DB가 없으면 새로 만들어줍니다.

### 5. 내 레포에 저장
```bash
git add .
git commit -m "setup: 워크스페이스 초기 설정"
git push
```

## 매일 사용 흐름

```
출근 → /work-start   # 오늘 할 일 노션 생성
퇴근 → /work-end     # 완료/메모 기록 + 내일 할 일 준비
```

---

## 스킬 목록

| 스킬 | 설명 |
|------|------|
| `/setup` | 최초 1회 온보딩 — 개인 설정 + 노션 연결 + 문서 폴더 구성 |
| `/work-start` | 오늘 업무 시작 — 스프린트 기반 할 일 제안 + 노션 일지 생성 |
| `/work-end` | 오늘 업무 마무리 — 완료 기록 + 내일 할 일 준비 |
| `/memo` | 질문·아이디어·메모 즉석 노션 저장 ("이거 메모해줘"도 동작) |

## 노션 연동 구조

| 노션 항목 | 용도 |
|-----------|------|
| 업무 일지 DB | 날짜별 할 일/완료/메모 자동 기록 |
| 스프린트 항목 | 주간 목표 및 OKR 연결 |

## 파일 구조

```
├── CLAUDE.md                    # Claude 행동 지침
├── .gitignore
├── docs/                        # 프로젝트별 로컬 문서
│   └── {프로젝트}/
│       ├── meetings/            # 미팅 자료
│       └── plans/               # 기획 문서
└── .claude/
    ├── user-config.md           # 개인 설정 (setup 후 자동 생성)
    ├── notion-pages.md          # 노션 페이지 URL 맵 (setup 후 자동 생성)
    └── commands/
        ├── setup.md             # 온보딩 스킬
        ├── work-start.md        # 업무 시작 스킬
        └── work-end.md          # 업무 마감 스킬
```
