# Claude 업무 워크스페이스 템플릿

> Claude Code + Notion으로 매일 업무를 자동 정리하는 비서 워크스페이스 템플릿

---

## 무엇을 할 수 있나요?

### 📋 매일 업무 일지 자동 생성
`/work-start` 한 번으로 오늘 할 일을 노션에 만들어줍니다.
스프린트 기반으로 오늘 마감 항목, 이월 항목을 분석해 3~5개를 제안하고, 확인하면 노션 페이지가 자동 생성됩니다.

### ✅ 하루 마무리 자동 기록
`/work-end`로 오늘 완료한 것/못한 것을 정리하면, 노션 일지를 업데이트하고 내일 할 일까지 미리 만들어줍니다.

### 📅 스프린트 관리
매주 월요일에 `/work-start`를 실행하면 새 스프린트 생성을 제안합니다. OKR 연결, 날짜 범위 자동 설정.

### 📝 회의록 자동 저장
`/meeting`으로 회의 내용을 전달하면 날짜+주제로 노션 페이지를 자동 생성합니다.

### 💬 질문·메모 즉석 저장
"이거 메모해줘" 한 마디로 아이디어, 참고 정보를 노션에 기록합니다.
대화 중 나온 답변도 Q&A 형태로 바로 저장 가능합니다.

## 시작하기

### 1. 이 템플릿으로 내 레포 만들기
GitHub에서 **Use this template** → 내 계정에 레포 생성

### 2. 로컬에 클론
```bash
git clone https://github.com/{내계정}/{레포이름}
cd {레포이름}
```

### 3. Notion MCP 연결
Claude Desktop 앱 → 설정(⚙️) → 통합(Integrations) → Notion → **Connect** 클릭

별도 API 키 발급 없이 버튼 한 번으로 연결됩니다.

### 4. Claude Code 실행 후 /setup
```
/setup
```

아래 과정이 자동으로 진행됩니다:
- 이름, 소속, 역할, 합류일 입력
- 노션 메인 페이지 URL 입력
- 노션 구조 자동 생성 (업무 일지 DB + 회의록 + 업무 메모 페이지)
- `.claude/user-config.md`, `.claude/notion-pages.md` 자동 작성
- `docs/` 폴더를 내 프로젝트에 맞게 구성

이미 노션 페이지가 있다면 URL을 붙여넣으면 기존 페이지에 연결해줍니다.

### 5. 내 레포에 저장
```bash
git add .
git commit -m "setup: 워크스페이스 초기 설정"
git push
```

## 스킬 목록

| 스킬 | 설명 |
|------|------|
| `/setup` | 최초 1회 온보딩 — 개인 설정 + 노션 구조 자동 생성 |
| `/work-start` | 오늘 업무 시작 — 스프린트 기반 할 일 제안 + 노션 일지 생성 |
| `/work-end` | 오늘 업무 마무리 — 완료 기록 + 내일 할 일 준비 |
| `/meeting` | 회의록 노션 자동 저장 — 날짜+주제 페이지 생성 |
| `/memo` | 질문·아이디어·메모 즉석 노션 저장 ("이거 메모해줘"도 동작) |

## 이 템플릿은 "틀"입니다

기본 구조(스킬, 노션 연동, 파일 레이아웃)는 잡혀 있지만, 실제로 쓸만한 비서가 되려면 **내 업무 방식에 맞게 고쳐야** 합니다.

### 무엇을 커스텀할 수 있나요?

| 항목 | 예시 |
|------|------|
| **CLAUDE.md 역할 정의** | "나는 마케터야, 캠페인 일정 중심으로 정리해줘" |
| **스킬 추가/수정** | `/weekly` 주간 리뷰, `/standup` 데일리 스탠드업 등 |
| **노션 구조** | 내 노션 DB 이름, 페이지 구조에 맞게 재연결 |
| **docs/ 폴더 구성** | 내 프로젝트 이름으로 폴더 추가 |
| **할 일 제안 방식** | 스프린트 기반 → OKR 기반, 칸반 기반 등으로 변경 |

### 커스텀 방법

```
1. /setup 으로 기본 개인 설정 완료
2. CLAUDE.md 하단 "현재 업무 상황" 채우기
3. 쓰다 불편한 부분 → Claude에게 "이렇게 바꿔줘"
4. 새 스킬 필요 → .claude/commands/ 에 파일 추가
```

> "CLAUDE.md 업데이트해줘", "이 스킬 수정해줘" 라고 말하면 Claude가 직접 파일을 고쳐줍니다.

> **새 스킬을 대화로 만들 수 있습니다.** "매주 월요일 주간 목표 정리하는 스킬 만들어줘" 처럼 말하면, Claude가 `.claude/commands/` 에 스킬 파일을 직접 작성해줍니다. 코드를 몰라도 됩니다.

```

├── .gitignore
├── docs/                        # 프로젝트별 로컬 문서

│       ├── meetings/            # 미팅 자료
│       └── plans/               # 기획 문서
└── .claude/
    ├── user-config.md           # 개인 설정 (/setup 후 자동 생성)
    ├── notion-pages.md          # 노션 페이지 URL 맵 (/setup 후 자동 생성)
    └── commands/
        ├── setup.md
        ├── work-start.md
        ├── work-end.md
        ├── meeting.md
        └── memo.md
```
